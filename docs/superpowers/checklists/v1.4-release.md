- [ ] In a supervised session, run `scripts/release-build.sh 1.4.0 41` with Developer ID signing and notarization configured, and the Sparkle appcast signing key in the keychain under account `AetherDesk`.
- [ ] Confirm the signed build's v1.3 handover check prints `OK`.
- [ ] Launch the OSS build and click **Check for Updates…**; confirm the Sparkle dialog appears.
- [ ] Run `scripts/release-publish.sh 1.4.0` as a dry run and review its output.
- [ ] Obtain explicit approval before running `scripts/release-publish.sh 1.4.0 --execute`.
- [ ] After publishing, use a real v1.3 installation to update to v1.4, then confirm **Check for Updates…** opens Sparkle.
- [ ] Confirm `brew install --cask sdelavega/tap/aetherdesk` works.
